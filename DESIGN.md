## 🎨 Design & UX

# Overall Direction

The app should feel visual, playful, and easy to use rather than like a traditional database or inventory management tool.

The wardrobe should feel like a visual gallery, while the outfit builder should feel like arranging paper cut-outs on a blank sheet of paper.

---

# 👗 Wardrobe

The wardrobe is displayed as a visual gallery where the user can see their clothing items at once.

# Layout

* Clothing items are displayed in a gallery/grid.
* Items should be visually prominent.
* The wardrobe should focus on the clothing images rather than large amounts of text.

# Filters

A filter section is available at the top of the wardrobe.

Possible categories include:

* All
* Tops
* Skirts
* Pants
* Overalls
* Dresses
* Shoes
* Other

Selecting a category filters the gallery to show only matching clothing items.

# Clothing Item

For the MVP, each clothing item contains:

* Image
* Name
* Category

---

# 📸 Upload Clothing

The user can add a new clothing item to their wardrobe.

# Required information

* Clothing image
* Name
* Category

The user should be able to select a category when uploading the item.

---

# 👚 Outfit Builder

The outfit builder should feel different from the wardrobe.

Instead of a traditional list or grid, the user sees a blank canvas resembling a sheet of paper.

Clothing items appear as cut-out paper pieces that can be arranged freely on the canvas.

# Interaction

The user should be able to:

* Select clothing items from their wardrobe
* Place them on the canvas
* Move items around
* Arrange items relative to each other
* Create an outfit composition
* Save the outfit

The goal is for the experience to feel similar to physically arranging paper clothing cut-outs on a sheet of paper.

# Visual Direction

* Blank paper-like canvas
* Clothing items without visible backgrounds
* Free positioning
* Layered clothing items
* Playful but clean visual style
